# Hotel Five Flavours of India 🍴

A static restaurant website built using **HTML & CSS**, showcasing authentic Indian cuisines from multiple regions.

## Features
- Multi-category menu: Breakfast, Lunch, Dinner, Drinks, Desserts
- Regional dishes from Maharashtra, Punjab, Rajasthan, Kerala & West Bengal
- Card-based UI with images and pricing
- Clean layout using CSS Grid
- Beginner-friendly, no frameworks used

## Tech Stack
- HTML5
- CSS3

## Purpose
This project was built for **learning front-end fundamentals** and understanding how real-world menu websites are structured.

## Limitations
- Static website (no backend)
- Limited accessibility optimization
- No JavaScript interactivity (yet)

## Future Improvements
- Mobile-first responsiveness
- External CSS refactoring
- JavaScript for filtering & navigation
- Accessibility & performance optimization
